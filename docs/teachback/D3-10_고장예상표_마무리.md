# 고장 예상표 마무리 (D3-10) — 📘 문서 담당 한재윤

> **초안.** 개인 노트의 원래 고장 예상표(P-8)는 저장소에 없다. 아래는 저장소에 남아 있는 기록(`DECISIONS.md`, `RUNBOOK.md`, `docs/eval/`)에서 확인되는 사실만 정리한 것이다. 원래 예상표의 문구와 대조해 "맞음 / 틀림" 판정은 한재윤이 확정한다. 확정이 필요한 칸은 `(원래 예상표와 대조)`로 표시했다.

## 1. 맞은 예상
| 예상한 고장 | 실제로 확인된 것 | 근거 |
|---|---|---|
| 03번: 반복되는 머리말·꼬리말이 본문에 섞인다 | 요소로 구분되어 걸러졌다(`Header` 4, `Footer` 2). 반복되는 10자 이상만 제거해 31개 → 27개 | `DECISIONS.md` 파싱 관찰 |
| 06번: 스캔본이라 글자로 읽히지 않는다 | `fast`에서 요소 0개, 인덱스에 청크 0개. 3일차에도 같음 | `DECISIONS.md`, 서버 인덱스 20청크에 06 없음 |
| 09번: 병합 셀, `〃`, 쪽을 넘는 표의 구조가 풀린다 | `Table` 0개, `Title` 128개. 청크 안에서 헤더 칸들이 먼저 나열되고 값이 따로 나온다 | `DECISIONS.md` 예상 확인 |
| 문서가 망가진 채 들어가면 에이전트가 엉뚱한 근거로 답한다 (예시 "06번이 빈 내용으로 들어감 → 오탐 기준을 물으면 엉뚱한 문서") | 06번이 빈 채로 들어가 Dify가 "정해진 n회 기준은 없다"고 틀리게 단정했다. 실제 규정은 "세 번 이상". 에이전트도 오탐 예외 규정을 못 봐 `it_inventory_script`를 오판했다 | `docs/advanced/dify.md`, D2-6 사례 ① |

## 3. 예상하지 못한 고장
| 고장 | 어디서 | 왜 예상하지 못했나 / 배운 점 |
|---|---|---|
| 03번 본문 소제목("3. 확산 범위 조사" 등)이 `Header`로 오분류된다 | 파싱 | 카테고리만 보고 지우면 본문 제목이 사라진다. 반복 여부까지 같이 봐야 한다 |
| **Dify가 External Knowledge API를 저장할 때 빈 검색어로 검증하고, 실제 임베딩에서는 서버가 500을 낸다** | 검색 API | 가짜 임베딩(`FAKE_LLM=true`)에서는 빈 문자열도 통과해서 전환 전에는 보이지 않았다. 가짜 모드로 만든 흐름은 실제 모드의 고장을 숨긴다 |
| 가짜 임베딩으로 적재·평가하면 점수가 달라진다(벡터 0.762 → 0.571, 합친 검색 0.857 → 0.667) | 평가 | 흐름 확인용 값을 성능으로 읽으면 안 된다 |
| 검색이 **관련은 있어 보이지만 틀린 문서**를 가져오면 Dify가 틀린 사실을 단정한다. 관련 청크가 아예 없으면 "모른다"고 답한다 | 검색·생성 | "근거 없음"보다 "비슷하지만 틀린 근거"가 더 위험하다 |
| 05번 소식지가 `isolate_host` 권고 출처로 1위에 올라왔다 | 검색 | 출처로 쓰면 안 되는 문서가 걸린다. Recall@1(0.667)과 연결된다 |
| 이 PC에서 `python -m soc.kb.ingest`가 Segmentation fault로 죽는다 | 환경 | 로컬 인덱스를 다시 만들 수 없어 적재값을 확인하지 못했고, 로컬과 서버 인덱스가 다른 상태가 됐다 |
| 로컬 `.env`의 `OPENSEARCH_URL`이 `localhost:92006`으로 틀려 있었다 | 환경 | 평가를 돌리기 전까지 발견하지 못했다. 설정 오타는 증상이 늦게 나타난다 |
| Service selector를 바꿔도 이미 열린 연결은 계속 동작해 증상이 늦게 나타났다 | 인프라(드릴) | 설정 변경과 증상 발생 시점이 다를 수 있다 (`RUNBOOK` D3-7-1) |

## 4. 한 줄 정리 (원래 예상표 대조 후 한재윤이 확정)
- 예상대로 깨진 것: 03 머리말·꼬리말, 06 스캔본, 09 표 구조.
- 예상과 달랐던 것: 표 구조가 풀려도 문서 단위 검색 점수는 높았다.
- 예상하지 못한 것: 빈 검색어(실제 임베딩에서만 드러남), 가짜 모드가 숨긴 고장, "비슷하지만 틀린 근거"의 위험, 환경 쪽 고장(로컬 ingest 크래시, `.env` 오타).
- 다음에 처음 볼 곳: 문서가 안 나오면 **적재 결과의 소스별 청크 수**(06이 0인지), 답이 이상하면 **검색 결과의 출처와 점수**, 평가가 이상하면 **가짜 모드인지(`FAKE_LLM`)와 인덱스 적재값**.
